# Java Full Stack - Spring Boot (Day 5-6)

This repository contains the Spring Boot practice project completed during Day 5 and Day 6 of Java Full Stack training.

## Topics Covered

- Spring Boot project setup
- Maven project structure
- REST API basics
- `@RestController`
- `@GetMapping`
- `@PostMapping`
- `@PathVariable`
- Getting data from URL path
- Creating simple logical programs using API endpoints
- Testing API endpoints

## Technologies Used

- Java
- Spring Boot
- Maven
- IntelliJ IDEA
- Postman

## Description

This project includes basic Spring Boot API programs using mapping annotations. `@GetMapping` was used to get data from the server, `@PostMapping` was used to send data, and `@PathVariable` was used to get values directly from the URL.

## Outcome

Basic backend API concepts were practiced using Spring Boot. Simple logical programs were created and tested through API endpoints.
